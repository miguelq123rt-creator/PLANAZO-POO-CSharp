# Capturas de pantalla

Guarda en esta carpeta capturas reales de la aplicación ejecutada desde la terminal. Se recomienda incluir:

1. El menú y la lista de eventos.
2. Una reserva confirmada y el resumen de reservas.
3. La salida de `dotnet run -- --pruebas` con todas las pruebas aprobadas.

No se agregan imágenes de ejemplo para evitar presentar capturas que no correspondan a una ejecución real en tu equipo.
